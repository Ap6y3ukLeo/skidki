# Скидки дня

Агрегатор акций российских сетей по городам: парсеры → `data/deals.json` → статический сайт на Astro.

## Сайт

Одна страница-приложение (`src/pages/index.astro` + `src/styles/app.css`):

- слева панель: поиск, чипы категорий, сортировка, карточка выбранного магазина или список магазинов, сетка товаров;
- справа карта на всю высоту: кастомные пины с максимальной скидкой, кластеры, зум, «найти меня», «искать в этой области»;
- на мобильных панель превращается в нижнюю шторку, карта на весь экран;
- тёмная и светлая тема, избранное в localStorage.

Данные для интерфейса: `public/data/deals.json` (копию пишет `collect.py`).

## Запуск

```powershell
# 1. собрать данные: города из stores.CITIES, порог скидки через --min
.venv\Scripts\python.exe collect.py Москва Королёв --min 30 --per-chain 2

# конкретные магазины вместо «ближайшего» (ключи вида kuper:983, magnit:773797)
.venv\Scripts\python.exe collect.py Москва --min 30 --store kuper:983

# 2. собрать и посмотреть сайт
$env:Path = "$env:LOCALAPPDATA\nodejs;$env:Path"
npm run build
npx astro preview --port 4321   # /moskva/ и /korolev/
```

## Источники

| Файл | Что делает |
|---|---|
| `magnit.py` | Магнит: магазин по bbox → акции → товары с ценой и скидкой (обычный HTTP) |
| `kuper.py` | Купер: товары со скидкой по магазину; закрывает Ашан, Ленту, Перекрёсток, Глобус, Дикси, Метро |
| `stores.py` | города, координаты, поиск ближайшего магазина |
| `collect.py` | сводит источники по городам в `data/deals.json` |
| `probe.py` | разведка: что сайт сети отдаёт без логина |
| `src/pages/[city].astro` | страница города: карта магазинов, фильтр по сети и магазину |

## Покрытие сетей

| Сеть | Источник | Адреса магазинов |
|---|---|---|
| Магнит | родной API | нет (только координаты) |
| Глобус, Ашан, Лента, Перекрёсток, Дикси, Метро, SPAR, ВкусВилл | Купер | да |
| Пятёрочка | — | блокирует IP (WAF X5) |

## Как собираются магазины

- `--per-chain N` — сколько магазинов каждой сети собирать (по умолчанию 2 на город).
- Купер отдаёт только ближайший к точке магазин, поэтому город обходится сеткой точек (`stores.CITY_POINTS`): каждая точка даёт свой «ближайший» магазин сети.
- Магнит ищет магазины по bbox и умеет отдавать сотни точек, но цены собираются по каждой акции отдельно, поэтому берутся ближайшие `N`.

## Как обходится защита

- Магнит и Купер пускают обычные HTTP-запросы, без браузера и прокси.
- Купер — единственный из агрегаторов, кто отдаёт товары со старой ценой и адресами магазинов без авторизации.
- Пятёрочка закрыта капчей Qrator: резидентиный прокси её не снимает, а браузерная сессия жрёт мегабайты и требует ручного прохода капчи на каждый запуск. Сбор с неё отключён.

## Ограничения

- Максимальная скидка сейчас ~63%, порог задаётся `--min`.
- Купер ограничивает выдачу 24 товарами на страницу, сбор идёт сортировкой по размеру скидки.
- `data/deals.json` перезаписывается целиком, история цен не хранится.
